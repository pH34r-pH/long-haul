# Fleet source handoff

The public Long Haul runtime is a source input to private [long-haul-fleet](https://github.com/pH34r-pH/long-haul-fleet). Fleet selects a full 40-character commit SHA on the trusted main/release history. `pyproject.toml` declares package `long-haul` version `0.1.0`, Python 3.11+, setuptools build metadata and runtime dependencies; `src/**` is the package, with public tests under `tests/**`.

The public `CI` workflow's stable required job is `test`. It runs `pip install -e '.[dev]'`, `python -m ruff check src tests`, and `python -m pytest -q` on each push/PR on GitHub-hosted runners with only `contents: read`. Fleet must verify a successful completed **main push** check on the exact selected SHA. A missing, skipped, pending, canceled, failed or PR-only check does not qualify it. The separate `Azure IaC validation/validate` job retains Bicep and static safety checks while legacy public IaC exists, but it no longer repeats the full Python test suite. The current `pyproject.toml` uses lower-bound dependency ranges; Fleet must record or constrain the resolved build environment to reproduce a package, rather than treating the source SHA alone as a full dependency lock.

After `test` passes on a main push, the `package` job builds from a clean archive of that exact commit on a public GitHub-hosted Python 3.11 Linux x86_64 runner. It pins pip, setuptools and wheel; builds the Long Haul wheel with its resolved runtime dependency wheels; verifies installation from the wheelhouse with network access disabled; and uploads `longhaul-offline-package-<source-sha>-<run-id>-<attempt>`. The artifact contains `longhaul-<source-sha>-offline.tar.gz` and `package-receipt.json`. The tarball contains `manifest.json` and the project/runtime wheels, with a SHA-256 and byte size for each file. The receipt binds those bytes to the source SHA, CI run/attempt, platform and artifact name. This is an immutable package candidate, not a deployment.

Fleet must recheck the successful main-push CI run and its `test` and `package` jobs, download the exact artifact with narrowly scoped `Actions:read`, recompute the bundle and member digests, inspect wheel metadata, and keep the approved bytes for any deployment or rollback. Later reruns can resolve different versions from the lower-bound dependencies; they cannot silently replace an already qualified package for the same release identity.

Fleet owns Azure credentials, runners, deployment, probes and rollback. This public repository's legacy Azure workflows remain a transition path under #40 until Fleet has deployed a checked source and verified recovery. Public CI does not carry private dispatch or OIDC authority. See Fleet #176/#177 for the protected identity and exact-SHA intake.
