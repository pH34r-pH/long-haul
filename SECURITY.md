# Security policy

Report vulnerabilities through GitHub private vulnerability reporting / Security Advisories when available rather than a public issue.

Security-sensitive areas include authority enforcement, work-contract capability boundaries, artifact/package verification, network/runtime adapters, checkpoint/evidence integrity, and infrastructure examples. Do not include real Fleet secrets, device identities, private addresses, or credentials in a report.

Long Haul's public runtime does not grant access to the private Fleet. A finding that depends on private deployment state should identify the public contract involved without publishing the private state itself.
